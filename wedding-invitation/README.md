## ลำดับหน้าการ์ด

1. **ฉากเปิด** ซองจดหมายสีชมพูผนึกตราครั่ง S·P แตะตราหรือปุ่ม → ตราแตก (หัวใจ + คอนเฟตตี) → ฝาซองเปิด → การ์ดรูปคู่เลื่อนขึ้น → ซูมเข้าการ์ด
2. **หน้าปก** รูปในกรอบโค้งทองสองชั้น ซูมช้าและเลื่อนแบบพารัลแลกซ์ ตราวันที่หมุน ชื่อสคริปต์สีทองโรสโกลด์
3. **การ์ดเชิญ** กระดาษพร้อมลายมุมทอง ขอบโฮโลแกรมทองหมุน โมโนแกรม S P ข้อความตรงตามการ์ด (บนคอมพิวเตอร์ การ์ดเอียงตามเมาส์)
4. **Save the Date** ขูดแผ่นทองเพื่อเปิดภาพวาด "22" จากการ์ดฉบับพิมพ์ · นับถอยหลังแบบพลิก (ถึง 07.09 น.) · บันทึกลงปฏิทิน / Google Calendar
5. **กำหนดการ** ไอคอนจากการ์ดฉบับพิมพ์ เส้นทองเติมตามการเลื่อน
6. **Our Love Story** แถบรูปสองแถววิ่งสวนกัน บนพื้นช็อกโกแลตประกายทอง
7. **เจ้าสาว & เจ้าบ่าว** · **Dress code** · **สถานที่** (แผนที่ฝัง + QR + ปุ่มนำทาง) · **อัลบั้ม** (แสดงครบทุกรูป) · **ขอบคุณ** (แชร์ + ดาวน์โหลดการ์ดฉบับพิมพ์)

## รูปภาพและหมายเลขรูป

1. ใส่รูปเพิ่มในโฟลเดอร์ `../Picture`
2. รัน `python tools/import_photos.py`

รูปใหม่จะได้หมายเลขถัดไป (001, 002, …) โดยหมายเลขของรูปเดิมไม่เปลี่ยน อัลบั้มแสดงทุกรูป
ดูว่ารูปไหนคือหมายเลขอะไรได้ที่ **`photo-numbers.html`** หรือ `photo-numbers.csv`
(การ์ดเชิญฉบับพิมพ์ถูกข้ามไว้ใน `SKIP` ของสคริปต์ และใช้แยกที่ `assets/images/invitation.jpg`)

รูปที่ตั้งด้วยมือใน `index.html`:

| ตำแหน่ง | รูป |
|---|---|
| ฉากเปิด (การ์ดในซอง) | `003-s.jpg` |
| หน้าปก + พื้นหลังจอกว้าง + ภาพพรีวิวลิงก์ | `002.jpg` (`002-s.jpg` ใน `css/base.css`) |
| เจ้าสาว / เจ้าบ่าว | `011-s.jpg` / `010-s.jpg` |
| แถบ Love Story | `014`–`019` และ `005`–`009`, `001` |
| ท้ายการ์ด | `004-s.jpg` |

## แก้ไขบ่อย

| อยากแก้ | ไปที่ |
|---|---|
| ชื่อ ผู้ใหญ่ ลำดับพิธี ข้อความ | `index.html` |
| เวลานับถอยหลัง / รายละเอียด Google Calendar | `WEDDING_START` / `WEDDING_END` / `CALENDAR` ใน `js/countdown.js` (และ `wedding.ics`) |
| สีธีม | ตัวแปร `:root` ใน `css/base.css` |
| จังหวะการเปิดซอง | `STEP_*` ใน `js/intro.js` (ต้องตรงกับ transition ใน `css/intro.css`) |
| ข้อความตอนแชร์ | `SHARE_TEXT` ใน `js/dock.js` |

หลังแก้ CSS/JS ให้รัน `sh tools/bump-version.sh` ทุกครั้ง ไม่งั้นเบราว์เซอร์อาจใช้ไฟล์เก่า

## ขึ้นเว็บ (deploy)

> **ระวัง:** โฟลเดอร์นี้คัดลอกมาจากการ์ดของ อ.ณัท & อ.โจ้ remote `origin` จึงยังชี้ไปที่ `Thonganek/wedding` (repo ของการ์ดคู่นั้น)
> ถ้า push ตอนนี้ การ์ดของคู่นั้นจะถูกแทนที่ ให้สร้าง repo ใหม่สำหรับการ์ดนี้ก่อน แล้วเปลี่ยน remote:
>
> ```sh
> git remote set-url origin https://github.com/<user>/<repo-ใหม่>.git
> ```

```sh
sh tools/bump-version.sh
git add -A && git commit -m "..." && git push
```

เมื่อได้ที่อยู่เว็บจริงแล้ว ให้เพิ่ม `og:url` และ `og:image` (URL เต็มไปที่ `assets/images/og.jpg`) ใน `<head>` ของ `index.html`

ประวัติ git ของการ์ดต้นแบบ (คู่อื่น) เก็บไว้ในเครื่องที่ branch `template-history` และ remote `old-template` เท่านั้น
**ห้าม push branch นั้นขึ้น repo ใดๆ** เพราะมีรูปและข้อมูลส่วนตัวของคู่เดิม
