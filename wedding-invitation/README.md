## ลำดับหน้าการ์ด

1. **ฉากเปิด** พื้นหลังเป็นรูปคู่บ่าวสาวจางๆ ย้อมโทนชมพูทอง เปลี่ยนรูปทุก 6 วินาที · ซองชมพูผนึกตราครั่ง S·P → แตะตรา: ตราแตก (เสียง + สั่น + หัวใจ/คอนเฟตตี) → ฝาซองเปิด → การ์ดรูปคู่เลื่อนขึ้น
   → ผงทองหมุนเป็นเกลียวรวมเป็นโมโนแกรม S·P → ระเบิดเป็นกลีบดอก → **หนังสั้น 6 วินาที** (รูป 4 ช็อต + แถบดำแบบภาพยนตร์ + ชื่อปิดท้าย) → เข้าการ์ด
   มีปุ่ม "ข้าม" ตลอด · **คนที่เคยเปิดแล้ว**จะได้ฉบับสั้น (ซอง → การ์ด) อัตโนมัติ
2. **เพลง** กล่องดนตรี Canon in D (สังเคราะห์ในเบราว์เซอร์ ไม่ต้องมีไฟล์) เริ่มตอนแตะตรา · ปุ่มแผ่นเสียงมุมขวาบนเปิด/ปิด · หยุดเองเมื่อสลับแอป
3. **หน้าปก** รูปทรงวงรี + วงรีสีแชมเปญชมพูวางเยื้องด้านหลัง + เส้นทองวงรีวางเยื้องพาดทับ มีแสงวิ่งรอบเส้น ·  ชื่อเขียนด้วย**หมึกทองทีละตัวอักษร**พร้อมปลายปากกาเรืองแสง (ใต้กรอบรูป)
   **เอียงมือถือ**แล้วภาพมีมิติ (รูป/กรอบ/ประกายขยับคนละระดับ) และตัวอักษรทองสะท้อนแสงตามมุม (iPhone ขออนุญาตตอนแตะตรา · คอมพิวเตอร์ใช้เมาส์)
4. **การ์ดเชิญ** ข้อความตามการ์ดฉบับพิมพ์ การ์ดเอียงตามมือถือ/เมาส์
5. **Save the Date** ขูดแผ่นทอง (มือถือสั่นเบาๆ ใต้นิ้ว) → ภาพ "22" เจ้าบ่าวเจ้าสาวเลื่อนเข้าหากัน หัวใจเต้นตรงกลาง · นับถอยหลัง · บันทึกลงปฏิทิน
6. **กำหนดการ** · **Our Love Story** · **เจ้าสาว & เจ้าบ่าว** · **Dress code**
7. **ซองออนไลน์** (แสดงเมื่อตั้งค่าใน `js/config.js` เท่านั้น)
8. **อัลบั้ม** สมุดภาพ 3 มิติพลิกหน้าได้ (แตะ/ปัด) + ภาพทั้งหมดแบบตาราง (แตะเพื่อดูภาพใหญ่)
9. **Photo Booth** เลือกพื้นหลังได้ 6 แบบ (ครีม · ชมพู · กลีบกุหลาบ · แชมเปญ · ช็อกโกแลต · คืนโคมลอย) เปลี่ยนได้ทั้งตอนถ่ายและหลังถ่าย · เซลฟีหรือเลือกรูปจากเครื่อง → ได้รูปในกรอบงานแต่งที่มี**รูปฝนและโต้ง**แปะอยู่ → บันทึก/แชร์
10. **ขอบคุณ** (แชร์ + ดาวน์โหลดการ์ดฉบับพิมพ์)
11. **ลอยโคมอวยพร** เขียนคำอวยพร → ปล่อยโคมลอยขึ้นฟ้ายามค่ำ · แตะโคมเพื่ออ่าน
12. **สถานที่จัดงาน** (ล่างสุด) แผนที่ฝัง + QR + ปุ่มนำทาง

**โหมดวันงาน (อัตโนมัติตามเวลาไทย):** 21 พ.ย. ขึ้น "พรุ่งนี้วันงานแล้ว" · 22 พ.ย. ขึ้น "ตอนนี้: <พิธี>" และกำหนดการติดป้าย เสร็จแล้ว / กำลังจัดอยู่ / ถัดไป · หลังงานขึ้นข้อความขอบคุณ
ลองดูล่วงหน้าได้ด้วย `index.html?now=2026-11-22T08:30`

## ตั้งค่าเพิ่มเติม — `js/config.js` ไฟล์เดียว

| ค่า | ใช้ทำอะไร | ถ้าเว้นว่าง |
|---|---|---|
| `endpoint` | URL Web App ของ Google Apps Script — เก็บคำอวยพรลง Google Sheet และแสดงโคมของแขกทุกคน | แขกส่งคำอวยพรเป็นข้อความ LINE ถึงบ่าวสาว · โคมของแขกเห็นเฉพาะในเครื่องตัวเอง |
| `music` | ไฟล์เพลง เช่น `assets/audio/song.mp3` (ใช้เพลงที่มีสิทธิ์ใช้) | เพลงกล่องดนตรี Canon in D |
| `gift` | `qr` รูป QR พร้อมเพย์ · `bank` · `name` · `account` | ไม่แสดงส่วนซองออนไลน์ |
| `sharedAlbum` | ลิงก์อัลบั้มกลาง (เช่น Google Photos) ให้แขกอัปโหลดรูปวันงาน | ไม่แสดงปุ่ม |

**เปิดระบบเก็บคำอวยพร:** ทำตามขั้นตอนที่หัวไฟล์ `tools/apps-script.gs` (สร้าง Google Sheet → วางโค้ด → Deploy เป็น Web app → เอา URL มาใส่ `endpoint`)
ซ่อนคำอวยพรที่ไม่เหมาะสมได้โดยพิมพ์ `no` ในคอลัมน์ "แสดง" ของชีต

## รูปภาพและหมายเลขรูป

1. ใส่รูปเพิ่มในโฟลเดอร์ `../Picture`
2. รัน `python tools/import_photos.py`

รูปใหม่ได้หมายเลขถัดไป (001, 002, …) รูปเดิมหมายเลขไม่เปลี่ยน อัลบั้มและสมุดภาพแสดงทุกรูป
ดูว่ารูปไหนคือหมายเลขอะไรได้ที่ **`photo-numbers.html`** หรือ `photo-numbers.csv`
(การ์ดเชิญฉบับพิมพ์ถูกข้ามไว้ใน `SKIP` ของสคริปต์ และใช้แยกที่ `assets/images/invitation.jpg`)

รูปที่ตั้งด้วยมือ:

| ตำแหน่ง | รูป |
|---|---|
| ฉากเปิด (การ์ดในซอง) | `003-s.jpg` ใน `index.html` |
| ฉากเปิด (พื้นหลังจางๆ) | `002`, `003`, `013`, `009`, `011`, `004` ใน `index.html` (`.intro__photos`) |
| หนังสั้น | `003`, `013`, `012`, `009` ใน `index.html` (`.cinema`) |
| หน้าปก + พื้นหลังจอกว้าง + ภาพพรีวิวลิงก์ | `002.jpg` (`002-s.jpg` ใน `css/base.css`) |
| เจ้าสาว / เจ้าบ่าว | `011-s.jpg` / `010-s.jpg` |
| แถบ Love Story | `014`–`019` และ `005`–`009`, `001` |
| ท้ายการ์ด | `004-s.jpg` |
| รูปคู่ในกรอบ Photo Booth | `python tools/make_booth_photo.py 002` (เปลี่ยนเลขรูปได้) → สร้าง `js/booth-photo.js` |

## ขึ้นเว็บ (deploy)

> **ระวัง:** โฟลเดอร์นี้คัดลอกมาจากการ์ดของ อ.ณัท & อ.โจ้ remote `origin` จึงยังชี้ไปที่ `Thonganek/wedding` (repo ของการ์ดคู่นั้น)
> ถ้า push ตอนนี้ การ์ดของคู่นั้นจะถูกแทนที่ ให้สร้าง repo ใหม่สำหรับการ์ดนี้ก่อน แล้วเปลี่ยน remote:
>
> ```sh
> git remote set-url origin https://github.com/<user>/<repo-ใหม่>.git
> ```

```sh
sh tools/bump-version.sh
git add -A && git commit -m "..." && git push
```

เมื่อได้ที่อยู่เว็บจริงแล้ว ให้เพิ่ม `og:url` และ `og:image` (URL เต็มไปที่ `assets/images/og.jpg`) ใน `<head>` ของ `index.html`
ฟีเจอร์เอียงมือถือและกล้อง Photo Booth ต้องเปิดผ่าน https (GitHub Pages ใช้ https อยู่แล้ว)

ประวัติ git ของการ์ดต้นแบบ (คู่อื่น) เก็บไว้ในเครื่องที่ branch `template-history` และ remote `old-template` เท่านั้น
**ห้าม push branch นั้นขึ้น repo ใดๆ** เพราะมีรูปและข้อมูลส่วนตัวของคู่เดิม
